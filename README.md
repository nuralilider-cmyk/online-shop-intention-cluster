# online-shop-intention-cluster
В этом проекте используется алгоритм K-means для распределения пользователей интернет-магазина по группам на основе множества факторов, таких как количество посещенных страниц, проведенное на них время, среднее значение страниц и так далее.

Цель этого датасета Revenue, который показывает купил ли пользователь продукт или нет
__________________
Research Question:
> **Как признак PageValues влияет на результаты кластеризации пользователей интернет-магазина с помощью алгоритма K-Means и вероятность совершения покупки в разных кластерах?**

# Подготовка данных

Признаки были разделены на две группы: числовые и категориальные

Для числовых признаков используется StandardScaler(), чтобы привести значения к примерно одному масштабу. Это важно, потому что K-Means работает с расстояниями между точками.

Для категориальных признаков используется OneHotEncoder(). Например, номер региона или браузера не означает, что один из них «больше» другого, поэтому их нельзя просто использовать как обычные числа.

Перед обучением также проверяются пропущенные значения и дубликаты.

Выбор количества кластеров

Для выбора количества кластеров проверяются значения k от 2 до 8.

Используются две метрики:

Inertia-показывает, насколько близко точки находятся к центрам своих кластеров;
Silhouette Score-показывает, насколько хорошо кластеры разделены между собой.

На основе этих результатов выбирается подходящее количество кластеров.
_______________
# Сам алгоритм K-Means

После подготовки данных запускается алгоритм K-Means.

Он работает примерно так:

Выбираются начальные центры кластеров.
Каждый пользователь относится к ближайшему центру.
Центры пересчитываются.
Пользователи снова распределяются между кластерами.
Это повторяется до тех пор, пока результат не стабилизируется.

После этого каждому пользователю присваивается номер кластера.
____________________
# Анализ кластеров

После создания кластеров сравниваются средние значения признаков в каждой группе.

Например:

сколько страниц обычно просматривают пользователи;
сколько времени проводят на сайте;
какие у них BounceRates и ExitRates;
какой процент пользователей является Returning Visitor;
отличаются ли группы по другим признакам.

Так можно понять, чем разные группы пользователей отличаются друг от друга.

Например, один кластер может состоять из более активных пользователей, которые просматривают много страниц и проводят больше времени на сайте, а другой — из пользователей, которые быстро уходят.

Покупки в разных кластерах

После создания кластеров используется Revenue, чтобы посмотреть процент покупок в каждой группе.

Получились примерно такие значения:

0.6%;
6.3%;
15.9%;
28.6%.

Получается, что разные группы пользователей имеют очень разную вероятность совершения покупки.

При этом K-Means не использовал Revenue при создании кластеров. Это один из главных результатов проекта: по поведению пользователей удалось выделить группы, которые сильно отличаются по проценту покупок.

Эксперимент с PageValues

Отдельно была проверена роль признака PageValues.

Для этого K-Means был запущен два раза:

со всеми признаками;
без PageValues.

# Сравнение результатов
Чтобы сравнить результаты обеих запусков, можно использовать adjusted rand index
Получилось:
ARI ≈ 0.996
Это значение очень близко к 1, поэтому можно сделать вывод  что после удаления PageValues структура кластеров почти не изменилась.
Нельзя просто сравнивать Cluster 0 первой модели с Cluster 0 второй модели, потому что номера кластеров могут меняться.
